# Personal Portfolio Website

[![Ask DeepWiki](https://devin.ai/assets/askdeepwiki.png)](https://deepwiki.com/aj-0-pius/aj_0_pius.github.io)

This repository contains the source code for a personal portfolio website for Minhajul Abadin Pius. It is a responsive, single-page application designed to showcase professional skills, services, and personal projects. The site is built with HTML, CSS, and interactive JavaScript features.

You can view the live website at: **[https://aj-0-pius.github.io/](https://aj-0-pius.github.io/)**

## Features

*   **Responsive Design:** The layout is fully responsive and optimized for viewing on desktops, tablets, and mobile devices.
*   **Dynamic Typing Animation:** The home section features a typing animation that cycles through various roles like "Developer," "Network Security," and "Cyber Security."
*   **Sticky Navigation:** The navigation bar becomes fixed to the top of the screen on scroll for easy access to all sections of the page.
*   **Skills Showcase:** An animated skills section with progress bars visually represents proficiency in technologies like HTML, Python, and JavaScript.
*   **Services Section:** Clearly outlines the key services offered, including Web Design, Cybersecurity, and App Design.
*   **Contact Links:** Provides direct links to social media profiles such as LinkedIn, Instagram, Twitter, and GitHub.
*   **Scroll-to-Top Button:** A convenience button that allows users to quickly return to the top of the page.

## Technologies Used

*   **Frontend:** HTML5, CSS3, JavaScript
*   **Libraries:**
    *   [jQuery](https://jquery.com/)
    *   [Typed.js](https://github.com/mattboldt/typed.js/) (for the typing animation)
    *   [Waypoints.js](http://imakewebthings.com/waypoints/) (to trigger events on scroll)
    *   [Owl Carousel 2](https://owlcarousel2.github.io/OwlCarousel2/)
*   **Fonts & Icons:**
    *   [Google Fonts](https://fonts.google.com/) (Poppins & Ubuntu)
    *   [Font Awesome](https://fontawesome.com/)

## Getting Started

To run this project on your local machine, follow these steps:

1.  **Clone the repository:**
    ```bash
    git clone https://github.com/aj-0-pius/aj_0_pius.github.io.git
    ```

2.  **Navigate to the project directory:**
    ```bash
    cd aj_0_pius.github.io
    ```

3.  **Open in a browser:**
    Open the `index.html` file in your web browser to view the website.
